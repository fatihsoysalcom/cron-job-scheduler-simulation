# Cron Job Scheduler Simulation

This Python script simulates a cron job scheduler. It allows you to define scheduled tasks using cron-like syntax and demonstrates how to parse these schedules and check if a task is due to run based on the current time. It's a simplified model for understanding cron's core logic.

## Language

`python`

## How to Run

Save the code as `cron_simulator.py` and run it from your terminal using `python cron_simulator.py`. Press Ctrl+C to stop the simulation.
